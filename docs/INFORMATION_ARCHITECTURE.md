# FRAME X AI — Information Architecture & Screen Map

Primary navigation: Home → Chat → History → Projects → Search.
Secondary/system navigation: Categories → Providers → Models → Google Drive → Settings → Profile.

Chat contains conversation title, provider/model/mode, routing explanation, message thread, Markdown/code, attachments, voice, copy/regenerate/retry, composer and challenge mode.

Providers contain provider status, secure key count, model registry, capability states and manual selection. Unknown capabilities are never treated as supported.

Drive contains authorization, folder structure, last sync, progress, offline queue and conflict resolution.

Settings contains appearance, accessibility, routing, credentials, Drive, privacy/security and account/session controls.

Mobile uses bottom navigation for the five primary destinations; secondary destinations live in the navigation drawer. Desktop uses a persistent sidebar.

Capability surfaces (voice, image generation, files/PDFs and research/tools) appear only when provider/model capability state permits them. Unsupported is disabled with explanation; unknown is not assumed to work.
