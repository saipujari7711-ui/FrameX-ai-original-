# FRAME X AI Brand Assets

Required derivatives:
- framex-logo-master.png — untouched supplied artwork
- framex-icon-1024.png — launcher/adaptive-icon source

Brand rule: do not redesign, redraw, recolor, or replace the supplied logo. Technical derivatives may crop or resize it while preserving the original visual identity.

Binary asset upload is intentionally kept separate from architecture commits so the source artwork is not altered or substituted.
